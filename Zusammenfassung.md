# Zusammenfassung IPT1

## Lernsession 1: Programmieren und Debugging

Ich habe gelernt, wie man Fehler in Programmen findet und behebt.
Ausserdem habe ich gelernt, wie man im Team arbeitet. Der Driver 
bedient den Computer und der Navigator kontrolliert die Arbeit 
und hilft. Wir haben auch die Begriffe Objekt, Attribut, Ereignis, 
Verhalten und Variable kennengelernt.

## Lernsession 2: Git und GitHub

Ich habe gelernt, dass Git Änderungen und Versionen eines Projekts 
speichert und GitHub eine Plattform für die Zusammenarbeit ist. 
Ich habe wichtige Git-Befehle wie `git status`, `git add`, 
`git commit` und `git log` kennengelernt. Ausserdem habe ich 
gelernt, was ein Repository, ein Branch und ein Commit sind.

## Lernsession 3: GitHub-Flow und Markdown

Ich habe gelernt, wie der GitHub-Flow funktioniert. Er besteht aus Issue, Branch, 
Commit und Pull Request. Ausserdem habe ich Markdown kennengelernt. Damit kann man 
Texte mit Überschriften, Listen, Links und Code formatieren. Das habe ich beim Erstellen 
und Verbessern eines README für mein Portfolio angewendet.
